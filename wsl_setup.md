# Setting Up WSL (Ubuntu) on Windows — Step-by-Step Guide

## Overview
This guide walks you through installing **Windows Subsystem for Linux (WSL)** with **Ubuntu**, configuring the environment, enabling WSL2, and preparing a full developer setup (Git, SSH, Python, Node, Go, Docker, etc.).

---

# 1. Prerequisites
- Windows 10 *or* Windows 11  
- Admin privileges  
- Microsoft Store access (optional—manual install instructions included)

---

# 2. Install WSL + Ubuntu

Install via Command
Open **PowerShell as Administrator**:

```powershell
wsl --install
```

# 3. Open

Open your command prompt and type in: ```wsl```

Or in the search bar try searching Ubuntu
